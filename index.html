IT SUPPORT CASE STUDIES

Problem → Diagnosis → Resolution

01User cannot log in

Checked the account in Active Directory, verified lockout status, unlocked or reset the account, and validated successful authentication from the client.

02Client has no network access

Used ipconfig /all, ping, and DNS tests to isolate whether the issue was DHCP, DNS, gateway, or server connectivity.

03Apache website unavailable

Checked systemctl status apache2, verified port 80, reviewed firewall rules, restarted the service when required, and retested from a Windows client.

04Printer output problem

Checked connectivity, driver and print queue status, restarted the print service, performed a test print, and documented the corrective action.
